# Discord Farm Bot

## Локальный запуск
```bash
cp .env.example .env      # вписать токен
docker compose up -d --build
docker compose logs -f
```
Все команды (кроме `!test`) требуют прав **Администратора** на сервере.

| Команда | Описание |
| :--- | :--- |
| `!test` | Принудительно отправляет в канал сообщение с кнопками, не дожидаясь 3-часового таймера. Команда автоматически удаляется после вызова. |
| `!log` | Выгружает последние 10 записей из лога действий в виде Excel-файла (`Logs.xlsx`). |
| `!log 50` | Выгружает последние 50 записей (можно указать любое число) в Excel-файл. |
| `!logcount` | Показывает общее количество записей (нажатий на кнопки) за всё время. |
| `!clearlog` | Полностью очищает историю действий (удаляет данные из памяти и файла `clicks.json`). |

## Данные
Хранятся в volume `farm-data` (`/app/data`): `clicks.json`, `state.json`, `Logs.xlsx`.

## Переменные окружения
| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `DISCORD_TOKEN` | ✅ | — | Токен бота |
| `CHANNEL_ID` | ❌ | `1197494268353314882` | ID канала с кнопками |
| `REMINDER_HOURS` | ❌ | `3` | Интервал напоминаний |
| `DATA_DIR` | ❌ | `/app/data` | Папка данных внутри контейнера |
